---
name: implement-change
description: 在本仓库实现明确的功能或修复任务，按验收条件交付代码、必要回归覆盖及可审查 PR。
---

读取根及相关目录的 AGENTS.md，识别目标仓库、基线、当前工作树和任务验收条件。
保留已有改动，在任务分支内推进。必要信息缺失时先完成不依赖该信息的调研，再报告具体阻塞。

先复现问题或确定可观察的目标行为，再修改直接相关的实现。
沿用现有架构和工具链；行为变更补必要回归覆盖，不为低影响改动写镜像测试。

使用 tools/agent.sh 中的入口。缺少工具链、配置或服务时先定位环境问题；
不能通过跳过失败检查把任务报为成功。环境修复超出授权范围时报告 Blocked。

实现稳定后形成提交，使用 verify-change 对当前交付版本做最终验证。
按任务授权推送分支并创建/更新 PR；提供变更、测试、证据和未验证项。
后续审查要求修复时沿用同一任务分支，重新核对受影响验证。
不要合并 PR 或改写无关分支。

当收到同一问题的第二次无进展反馈或累计第三轮返工仍失败时，
停止重复尝试，返回根因证据和需要人的具体决定。用户可以明确调整这个起步预算。
