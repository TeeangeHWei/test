---
name: verify-change
description: 验证当前代码变更，运行本仓库检查和核心流程并交付绑定提交版本的测试结果、证据及未验证项。
---

读取 AGENTS.md、需求、当前 diff 及 tools/agent-commands.sh。
先确认仓库、分支、提交 SHA 和工作树；证据需说明测试的是提交还是尚未提交的工作树。

执行 bash tools/agent.sh checks 和 bash tools/agent.sh smoke。
需要交互验证时，在独立终端用 bash tools/agent.sh start 启动应用并等待实际就绪。
CI 的 smoke 应自行管理服务生命周期，不依赖开发会话已启动的进程。

按验收条件核对真实结果：
- UI：操作关键流程，检查最后状态，提供截图/录像。
- API/CLI：执行有断言的请求或命令，提供脱敏结果。
- 功能修复：确认原问题已被覆盖，并核对相关回归。

保存或附上可审阅证据，注明当前提交、时间、环境、命令和结果。
新推送后重新判断旧证据是否仍覆盖变更；涉及的代码改变时重新执行相关验证。
CI 若测试合并提交，同时记录该版本与 PR head 的关系。

无法运行、入口未配置、无断言、非零退出均应报告失败/未验证。
不宣称覆盖未执行的平台或环境；明确区分通过、失败、不适用和未验证。
纯文案等改动可使用相称验证，但需说明省略行为测试的理由。

只报告实际获得的链接和产物；本地文件尚未共享时明确说明。
